## Featured Projects & Work 💻

### [Courtat](https://courtat.io) 🎾

**Building a product. Developing the technical skills to take it further.**

I founded and built Courtat from scratch to help sports communities manage their sessions. What began as a Replit prototype became a practical education in software development, database design, automation, and production operations.

Using Codex and other AI coding tools, I translated organizer requirements into working software, investigated failures, refined the architecture, and tested changes against real workflows.

Courtat brings together player registration, cancellations, waiting lists, court allocation, payment tracking, and financial reconciliation. Its WhatsApp integration connects existing group workflows with structured session management.

#### Key Milestones & Skills

- **Prototyping & modelling:** Started on Replit, translating organizer workflows, player preferences, and financial rules into structured data and court-allocation logic.
- **Infrastructure & data integrity:** Moved to GitHub and Codex, migrated to Cloudflare Workers/D1, and developed AI-assisted Python and JavaScript tools for verified backups, guarded recovery, and database reconciliation.
- **Understanding production complexity:** Refined WhatsApp synchronization, debugged authentication and session failures, reduced database calls, and strengthened error handling, rate limiting, and regression tests.
- **Native mobile development:** Built a React Native/Expo iOS app and progressed to TestFlight, working with push notifications, Live Activities, bilingual interfaces, and performance profiling.

**Skills developed:** TypeScript · React · React Native · Python · SQL · API integration · Event-driven systems · Git · Cloud deployment

### Equipment & Systems Design ⚙️

I work on equipment concepts and system configurations for poultry biosecurity and processing hygiene, translating site requirements into practical technical solutions.

My work includes:

- **Chemical dosing and dilution:** Configuring proportional dosing systems, chemical preparation stations, and application equipment.
- **Cleaning and disinfection systems:** Planning rinse, foam, and disinfection setups around facility layouts and operating requirements.
- **Equipment integration:** Developing component layouts, connection diagrams, and installation concepts with attention to operation and maintenance.
- **Operational improvement:** Turning site assessments into equipment recommendations, cleaning procedures, training plans, and performance verification.
